# Статья: рабочая рукопись от 10 сентября 2026

Главное обновление C038: доказана аналитическая теорема
`beta(L(R),w)=alpha(L(R),w)=nu(R,w)` для любого конечного line graph и
любых неотрицательных весов. Доказательство связывает Majorana-билинейную
форму, ядерную норму кососимметричной матрицы и полный matching polytope
Эдмондса. Семейство `L(K_(2k+1))` даёт бесконечное строгое отделение от
ранее достаточного класса h-perfect графов. Приоритет теоремы ещё должен
быть подтверждён внешним литературным и математическим рецензированием.

Обновление исследования C031: [фиксированное неравенство C014 теперь доказано точно](../C031_DIXON_GATE.md),
beta(G,w)=6. Текущий локальный main.tex уже включает этот результат.
Старые опубликованные PDF и описания могут предшествовать ему; подготовленная
сборка этого цикла находится в output/pdf/prepared_20260910.
Публикационная новизна и готовность A* этим сертификатом не подтверждены.

дал отрицательный результат: noisy_score не прошёл зарегистрированный

Название: **Matching polytopes as exact Pauli uncertainty bodies: all line graphs and a simplicial claw-free frontier**.

Это связная англоязычная математическая рукопись с аннотацией, формулировками,
доказательствами, вычислительными результатами, ограничениями, литературой
и приложением о воспроизводимости. Не заявка о достигнутом A* и не
общая теорема для всех SCF. C014 закрыт для фиксированных весов, не для всех весов.

## Основные результаты статьи

Для всех line graphs задача точного weighted Pauli uncertainty сводится к
maximum-weight matching. Это произвольный размер, произвольные веса и
аналитическое доказательство, а не экстраполяция конечного census. Новый
аудит проверяет матричную оценку на 1245 непустых корневых графах атласа и
47 прямых плотных Jordan--Wigner реализациях, а также содержит независимые
точные проверки separation-свидетелей `L(K5)`, `L(K7)`, `L(K9)`. Отдельный
[adversarial priority audit](../LINE_GRAPH_PRIORITY_AUDIT_C038.md) сравнивает
результат с ближайшими работами по beta-body, free fermions, magic,
measurement incompatibility и skew energy.

Для явно определённого семейства G_m порядка 2m+8 доказано равенство
взвешенного квантового beta-числа и взвешенного числа независимости при
любом m и любых неотрицательных весах. В тексте приведены:

- знаково-согласованная матрица Грама и точные transfer-тождества;
- скалярная оценка с проверкой правильной спектральной ветви;
- описание фиксированного ядра и доказательство уточнения через транспортную задачу;
- 12-вершинное трёхстрочное расширение и два XX-следствия;
- фиксированная 24-операторная задача с точным сертификатом beta=6 (C031),
  исторические 1024 численных старта и точный theta-свидетель.

Более широкие результаты C010 и исторический census сохранены в репозитории,
но не объявлены дополнительными основными теоремами этой рукописи. Это
сужение делает доказательную цепочку статьи обозримой и явной.

## Сборка и проверка

Из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File experiments/pauli_fourth_moment_phase0/paper/build.ps1
```

Нужны Python 3 и установленный LaTeX с перечисленными в main.tex пакетами.
Сборка запрещает shell escape и автоматическую установку пакетов.
Итог: `output/pdf/weighted_pauli_uncertainty_manuscript.pdf`.
Редактируемый источник: `main.tex`.

`check_paper.py` сверяет ключевые числа и отрицательные scope-флаги с JSON,
проверяет 64 хеша и ссылки внутри LaTeX. Это не замена математических
верификаторов. Точные команды полного комплекта приведены в статье.
Не использовать Python `-O`; для полного unittest-набора не использовать `-S`.

Исследовательский snapshot: `4dc9dc7bc26cca5ea3a7f4cfa66cc4f7fc969a83`.
Прежняя чистая репродукция: 127 тестов за 441.989 секунды. Новая сборка
статьи сама по себе не является повторным выполнением этих 127 тестов.

## Что мешает назвать её готовой к подаче

1. Нужна внешняя проверка новой line-graph теоремы, основного SCF
   доказательства и точных сертификатов.
2. Поиск по ближайшим работам не обнаружил сформулированной line-graph
   hbar-perfect теоремы, но отрицательный поиск не доказывает приоритет.
3. Приоритет all-weight результата для SCF-семейства остаётся открытым:
   надо исключить эквивалентное следствие известных операций/вложений.
4. C014 доказан при фиксированных весах. Это не общая теорема композиции
   и само по себе не устанавливает литературный приоритет. Более широкий
   результат C010 пока сохранён отдельно от основных теорем рукописи.
5. Люди-авторы должны утвердить авторство, аффилиации, раскрытие AI-помощи,
   финансирование, целевое издание и окончательный текст. Эти сведения не выдуманы.
