# Cross-claw restrictions and the central-sector proof gate

Date: 2026-09-06. Cycle C004, preregistration `a3766c3`.
Status: elementary structural lemmas proved; quantum composition unresolved.
This note does not claim an A-star result or prove unrestricted H-SCF.

## 1. Exact structural condition across a separator

Write V=S union L union R, with these sets disjoint and L,R nonempty and
anticomplete. Assume G[S union L] and G[S union R] are claw-free. For s in S
write L_s=N(s) intersection L and R_s=N(s) intersection R.

Then G is claw-free if and only if BOTH of these conditions hold:

1. Whenever R_s is nonempty, L_s is a clique; whenever L_s is nonempty,
   R_s is a clique.
2. For every s,t in S with st an edge, at least one of
   `L_s subset N(t)` and `R_s subset N(t)` holds.

Proof. A claw not contained in a local side must have leaves in both L and
R. Its center must lie in S because there are no L-R edges. If two leaves
lie in one outside side, the first condition excludes it. Otherwise its
leaves are x in L, y in R and t in S, and the second condition excludes it.
Conversely, failure of either condition explicitly supplies the three
independent leaves and their common center. These exhaust the cases. QED.

Equivalently, for x in L and y in R put F=N(x) intersection S and
H=N(y) intersection S. The second condition requires

`N(s) intersection S subset F union H` for every s in F intersection H.

This characterization actually holds for ANY separator S. The clique-minus-
one-edge hypothesis is needed for the particular operator J below, not for
the cross-claw characterization. The local claw-free hypotheses cannot be
omitted: G8 from C003 has a left-side claw centered at 5 with leaves 0,1,2.

These statements are direct forbidden-induced-subgraph reasoning, not a
new graph-decomposition theorem. They do not establish quantum marginal
compatibility or a decomposition of every SCF graph.

## 2. Boundary centrality versus global centrality

Suppose S is a clique minus edge uv. The commuting Pauli involutions P_u
and P_v give a Hermitian involution `J=P_u P_v`. Every generator on S
commutes with J: the other separator vertices anticommute with both factors.
For any outside generator P_z, exactly

`J P_z = (-1)^(1_zu+1_zv) P_z J`.

Thus neighborhood patterns 00 and 11 are J-even; 01 and 10 are J-odd.
This is an exact commutation statement, not an assertion that a state can
be dephased in J without changing its squared expectations.

Proposition. In a connected claw-free graph, if J is central in the algebra
generated by ALL P_i, then alpha(G)=2.

Proof. Centrality says that the nonadjacent vertices u,v are false twins:
their common neighborhood is C=N(u)=N(v). If an edge cz joined C to a vertex
z outside C union {u,v}, then c with leaves u,v,z would induce a claw.
There are consequently no such edges. Connectivity gives
`V=C union {u,v}`. The set C has independence number at most two, since
three independent vertices of C would be leaves of a claw centered at u.
Every stable set is either contained in C or contained in {u,v}, so alpha
is two. QED. For disconnected graphs this applies only to the component
containing u,v; an unrelated component must not be discarded.

Hence global centrality cannot supply the missing alpha>=3 theorem: in the
connected SCF setting it returns to the already proved alpha-two class.
It does NOT follow that one-sided centrality is useless or that no
one-sided-central composition theorem can exist.

## 4. Exact warning: lossless J-dephasing is already false on C5

Use the five Pauli strings, in cycle order,

`(XI, ZX, IZ, IX, YZ)`, with weights `(1,1,1,3,1)`.

For the cut S={0,2}, J=XZ is central on the side {0,1,2}. The state
`|++>=(1,1,1,1)/2` has expectation profile `(1,0,0,1,0)` and weighted
squared value four. This equals the weighted stable bound, attained by
the stable set {0,3}; it does not violate hbar-perfectness.

For EVERY J-invariant state, the last two expectations vanish because
their observables anticommute with J. On the remaining P3 graph, the two
clique inequalities give `x0+x1+x2<=2`. The J-eigenstate
`|+0>=(1,0,1,0)/sqrt(2)` attains two. Consequently

`max_all_states sum w_i<P_i>^2 = 4`,

`max_[rho,J]=0 sum w_i<P_i>^2 = 2`.

For the first equality, the line-graph theorem supplies the upper bound;
alternatively, the known hbar-perfectness of C5 does. The actual pinching of
the displayed |++> state has value one, not the optimal J-invariant value
two. The distinction prevents confusing dephasing one state with optimizing
over the entire invariant-state class. Exact integer-vector verification
checks both explicit states and the odd/even commutation pattern.

This is an elementary control illustrating lost coherence, not a new
quantum advantage, graph counterexample or claim to priority.

## 5. What an operator proof must still control

For `H=sum_i a_i P_i`, split its J-even and J-odd terms. In the two J
eigenspaces H has blocks

`H = [[E_+, C], [C^dagger, E_-]]`.

The one-sided-central property locates the odd terms on one side, but it
does not set C to zero. In particular the off-diagonal block of H squared
is `E_+ C + C E_-`. Local sector bounds alone do not control this block.

Writing a positivity requirement for
`alpha(G,w) sum_i a_i^2/w_i I - H^2` is simply the original weighted
uncertainty problem in block notation (for positive weights; zeros require
restriction to support). It is not a derived bridge lemma. No noncircular
bound on the missing coherent block has been proved in C004.

The next gate therefore moves to an explicit transfer/SOS certificate,
retaining cross-sector terms. It will test a frozen order-ten weighted
facet rather than generate a larger graph census. A numerical SDP answer
alone will not be labelled a proof or a new algorithm.
