# Conformal Metamorphic Rank Transfer: frozen offline Phase 0

Freeze date: 2026-09-02.  This protocol was written before the main synthetic
cohort was generated or scored.

## 1. Question and claim boundary

The only candidate claim in this phase is:

> Disagreement among deliberately approximate, exact-equivalent simulation
> representations contains information about the error of a simulator-predicted
> *schedule ranking* on a noisy quantum device.  Used as a split-conformal local
> scale, that disagreement permits more correct non-abstaining schedule-sign
> decisions than strong margin, unscaled-conformal, and hardware-proxy
> baselines at the same accepted coverage.

The output is one of `A`, `B`, or `ABSTAIN` for the sign of a difference in a
predeclared application-event probability.  Phase 0 contains no QPU
observation.  Passing it can authorize a preregistered QPU experiment; it
cannot establish hardware performance, novelty, quantum advantage, or an A*
contribution.

The following broader claims are forbidden regardless of the result:

- generic circuit-quality or device-ranking prediction;
- error mitigation;
- a new conformal-prediction theorem;
- a hardware result inferred from a noise surrogate;
- treating correlated schedule pairs from one job as independent devices or
  calibration blocks;
- presenting MPS representation spread as a physical error bar.

## 2. Estimand

For graph block `i`, QAOA depth `d`, noise snapshot `u`, and two fixed schedules
`A` and `B`, let

`h_i,d,u = P_hw(event | A) - P_hw(event | B)`.

The event is: the measured bit string is an independent set whose cardinality
is at least `alpha(G)-1`, where `alpha(G)` is computed exactly before any noisy
simulation.  For simulator variant `v`, define the analogous noiseless
approximate gap `Delta_i,d,v`.  The metamorphic center and spread are

`m = median_v Delta_v`,

`s = max_v Delta_v - min_v Delta_v`.

CMRT uses calibration scores

`r_i = max_(d,u) |h_i,d,u - m_i,d| / (s_i,d + 1e-4)`.

The maximum is taken over every registered depth and primary noise snapshot in
a graph block.  This makes the resulting interval simultaneous within a held-
out graph rather than incorrectly treating its correlated rows as independent.
With `N` calibration graphs and `alpha=0.10`, the quantile is order statistic

`ceil((N+1)*(1-alpha))`, clipped to `N`.

The interval for each held-out row is

`[m-q(s+1e-4), m+q(s+1e-4)]`.

CMRT accepts a sign only when zero is outside this interval.  Exchangeability
supports the usual finite-sample statement only for graph blocks drawn from
the registered primary generator.  The deliberately shifted snapshot is an
out-of-distribution stress test and has no conformal coverage guarantee.

## 3. Frozen cohort

### Graph blocks

- Seed: `20260902`.
- 36 non-isomorphic connected simple graphs, six at each
  `n in {8,9,10,11,12,13}`.
- Maximum degree at most three, generated by a spanning tree plus admissible
  random chords and deduplicated by Weisfeiler-Lehman hash followed by exact
  isomorphism checking within a hash bucket.
- Whole-graph split: 24 calibration and 12 held-out graphs.  Assignment is by
  SHA-256 of `"cmrt-v1:" + graph_id`; the lowest 24 hashes calibrate.  No depth,
  schedule, or noise row from a held-out graph may enter calibration.
- Depths: `p in {2,3,4}`.

### Schedule selection

The schedule library and its order are fixed in `protocol.json`.  For each
graph-depth block, enumerate schedule pairs in that order using only exact
noiseless probabilities.  Select the first pair for which both event
probabilities lie in `[0.05,0.80]` and the absolute ideal gap lies in
`[0.02,0.20]`.  If none qualifies, retain the pair with ideal gap closest to
`0.08` and flag the row as a fallback.  Hardware/noisy outcomes never
participate in this selection.

### Metamorphic simulator family

Every chosen schedule is run with layerwise TT-SVD truncation after both cost
and mixer layers, using bond caps `{2,4,8}` and two exact-equivalent qubit
orders: natural order and a deterministic degree/BFS order.  The same physical
circuit and event are used; only the internal approximate representation
changes.  An untruncated exact statevector is retained as an audit and as an
explicitly advantaged baseline, but is not included in the CMRT spread.

### Synthetic device family

Three primary, predeclared noise snapshots apply coherent mixer/cost scale
error, deterministic edge-phase perturbations, readout bit flips, and a global
depolarizing mixture.  Their exact parameters and seeds are in
`protocol.json`.  A fourth stronger snapshot is held out as an
out-of-distribution stress test.  These are falsification surrogates, not claims
about any named QPU.

No shot sampling is used in the primary offline estimand, so a failure cannot
be blamed on finite-shot variance.  A separate 4,096-shot audit adds
Bonferroni-corrected binomial intervals and cannot improve the primary verdict.

## 4. Frozen baselines

All conformal baselines use the identical whole-graph split and block-maximum
score construction.

1. `unscaled_ensemble`: center `m`, constant scale one.
2. `gate_proxy`: center `m`, scale proportional to QAOA two-qubit phase count
   plus mixer count and depth, normalized on calibration data.
3. `single_high_bond`: the bond-8 degree/BFS prediction, constant scale.
4. `exact_noiseless`: exact statevector gap, constant scale.  This is an
   intentionally strong small-system upper baseline unavailable at target
   scale.
5. `nominal_noise`: a preregistered midpoint noise surrogate, constant scale.

For accepted-sign comparisons, methods are also compared at matched accepted
row count by ranking `distance of interval from zero / interval half-width`.
No method may obtain a different test set.

## 5. Binding decision gates

The CMRT mechanism is killed as an A*-oriented route if **any** condition holds
on the primary held-out split:

1. Spearman correlation between `s` and `|h-m|` is below `0.30`.
2. Fewer than 11 of 12 held-out graph blocks have all registered true gaps
   inside their CMRT intervals.
3. CMRT accepts fewer than 50% of held-out rows at at least 90% sign accuracy.
4. At CMRT's accepted row count, its sign-error rate is not at least 25%
   lower than every non-oracle baseline that can accept that many rows.
5. `exact_noiseless` or `nominal_noise` has no worse sign error and at least as
   much accepted coverage without wider median intervals.
6. The CMRT advantage disappears on either of the three primary snapshots.
7. The shifted-snapshot sign accuracy among accepted rows is below 80%, or its
   accepted coverage falls below 25%.
8. More than 10% of rows use the schedule-selection fallback.
9. A bug, split leakage, non-determinism, or exact-equivalence failure is found.
10. Prior art is found that already makes observable-specific conformal
    schedule-rank transfer from metamorphic simulator spread the operative
    contribution.

A pass means only `AUTHORIZE_HELDOUT_QPU_PHASE`; otherwise the terminal label
is `KILL_CMRT_AS_ASTAR_SOURCE`.  Thresholds will not be weakened after the
result is visible.

## 6. Real-hardware escalation, not part of Phase 0

Escalation requires fresh credentials and a live backend snapshot.  The frozen
target design is 24 hardware-native MIS graphs, 16 calibration and eight
held-out whole graphs, 4,096 shots for each of 48 main circuits plus 32,768
shots for each of two hard-control circuits.  Circuits in a compared pair must
share a physical layout and native two-qubit skeleton and be interleaved in one
runtime batch.  Raw counts are primary; mitigation is secondary.

An A*-level claim would additionally require at least two independent QPU
snapshots or devices, roughly 40 held-out graph blocks, preregistered comparison
to current hardware ranking/capability models, and a material selective-error
advantage.  This repository currently has no IBM or AWS credentials and no QPU
job is authorized merely by creating this packet.

## 7. Archived IBM data boundary

The local `ibm_boston` archive contains one job/snapshot, one 55-qubit
instance, 20 parameter circuits, and 1,000 shots per circuit.  Its 190 pairwise
comparisons are correlated and are not 190 calibration blocks.  Missing
calibration, exact transpiled-circuit lineage, and a second independent job
exclude it from every promotion gate.  It may be used only as a smoke test of
the ingestion and shot-interval code.
