# Correction log

## 2026-09-01: perturbed prefix inherited the wrong onsite fields

Discovered after the first host-transfer run and before writing the final
report.  The intended “unmodified first-r-atoms prefix” baseline must inherit
the first `r` target-motif detunings.  In the perturbed control, the initial
implementation instead reset them to the uniform mean `0.37`.

Impact:

- target and optimized-surrogate responses and errors are unchanged;
- only the perturbed prefix error and the claimed improvement factor were
  biased;
- the uniform control is unchanged.

Fix:

- `run_physical_surrogate.py`, `run_capacity_audit.py`, and
  `run_host_transfer.py` now use `onsite_detunings(r, regime)` for the prefix;
- every affected artifact is regenerated by rerunning the original frozen
  commands;
- no threshold or target case is changed.
