# Ограничения снимка

Этот ZIP содержит реальные доступные исходники, а не только ссылки. Однако это **курируемый снимок**, а не полный `git clone` всех 26 репозиториев с историей, моделями и многогигабайтными experiment outputs.

Включён исходный PDF AAMAS 2026. Другие черновики (RAVR-S, CIPHER, RG-HLI submission copies) ранее находились в File Library/анонимных submission-артефактах; некоторые содержат явное ограничение `Do not distribute`. Поэтому в этот переносимый ZIP они не копировались автоматически. Публичные RG-HLI README/results/reproducibility и ключевые исходники включены.

Файлы в `code/` — реальные снимки из GitHub. В некоторых больших репозиториях отобраны только наиболее релевантные файлы, чтобы архив оставался переносимым.
