# Broad ansatz-event rank-signature falsification

## Verdict

The broad claim “QAOA generically has decision rank below the event matching
cap” failed on new MaxCut data and is closed.

Three schedule pairs did have identical profiles and phase scrambling matched
the structural cap, consistent with generic-rank theory.  However, both
development graphs and both orderings saturated the cap already before phase
scrambling: **0/4 rows passed**.  The held-out graph was not run because the
frozen development gate failed.

This negative result narrows the surviving hypothesis to structured
symmetry-rich MIS ansatz/event pairs.
